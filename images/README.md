## NeoCogi COM

`neocogi-com.png` captures a terminal-style transcript of the actual calculator
plugin walkthrough from
[NeoCogi COM](https://github.com/NeoCogi/neocogi-com), revision `1909513`, using
the published matching `0.1.0` SDK, host, and IDL packages. This is an example-output
screenshot, rather than a graphical interface for the SDK.

The tutorial was copied into a temporary directory. Its plugin and host were
built independently, then the real host loaded the plugin and printed
`2 + 3 = 5`; its overflow assertion also completed successfully. The screenshot
shows the actual shared interface source and captured output. The transcript was
displayed in a local browser and captured at 1200 × 800; no application UI or
program results were invented. The example's MIT license is retained in
[neocogi-com-LICENSE.txt](neocogi-com-LICENSE.txt).
